# Archived OnPrez Documentation

Documents under this directory are **non-normative historical records**. They are retained to
explain earlier plans, fixtures, or implementation assumptions and must not be used as current
setup, architecture, product, security, or release guidance.

Start with [`../../CURRENT_STATE.md`](../../CURRENT_STATE.md). Current roadmap evidence lives in
[`../CRITICAL_ACTION_PLAN_PROGRESS.md`](../CRITICAL_ACTION_PLAN_PROGRESS.md).

Every archived Markdown document must include an `ARCHIVED — NOT CURRENT GUIDANCE` banner and a
link back to `CURRENT_STATE.md`. When useful historical facts conflict with active code, schema,
tests, runbooks, or canonical acceptance documents, the active sources win.
